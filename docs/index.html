The tools you already use

Born In The Command Line.

Agent ready

MCP + SKILL.md.

The MCP server gives your agent the tools; the skill file gives it the rules.

The MCP server

Thirty-odd tools to create, move, tag, comment, close and sync. Each agent works under its own name, so the log shows which agent did what.

SKILL.md

Sane defaults for your agent: work in a worktree, link commits to tickets, document the solution when done etc.
